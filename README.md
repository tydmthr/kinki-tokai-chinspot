# 異界巡礼 — 近畿・東海 珍スポット＆奇祭百景

> 表通りの観光案内には載らない、もう一つの日本。

近畿・東海地方の「一生記憶に残る系」珍スポット **50件** と、奇祭・カオスイベント **47件** を、インタラクティブ地図と年間カレンダーで巡るサイトです。

## 機能

| ビュー | 内容 |
|---|---|
| **序** | サイトの世界観とカテゴリ案内 |
| **地図** | MapLibre GLによるインタラクティブマップ。漢字マーカーでカテゴリ視覚化 |
| **祭暦** | 2026年5月〜2027年4月の月別グリッドカレンダー |
| **百景名鑑** | 全件カード一覧、検索可 |

## カテゴリ

- **土俗・奇祭**（祓） — 性、火、裸、奇習。千年の信仰の核心。
- **B級・カオス**（魁） — 個人が作った珍博物館、コンクリート像群。
- **心霊・廃墟**（霊） — 有名心霊、廃墟、いわく付きの場所。
- **聖地・ミステリー**（秘） — 巨石、UFO、ピラミッド、超古代史の影。

## データ

- `spots.json` — 珍スポット 50件
- `festivals.json` — 奇祭・年中行事 47件

各エントリは緯度経度、概要、見どころ、起源、公式URL、参考URLを含みます。

## 注意

- 心霊・廃墟スポットは私有地・立入禁止区域を含む場合があります。本サイトは来歴・歴史記録としての掲載で、来訪を推奨するものではありません。
- 祭事日程は変更される場合があります。訪問前に必ず公式情報で確認してください。
