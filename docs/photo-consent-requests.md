- **fest-024（那智の火祭）**: 和歌山県観光連盟。CC/PD表記なし。商用・本番掲載前に利用許諾連絡を推奨。

- **fest-156（甚目の虫送り）**: 松阪市産業文化部文化課（Tel: 0598-53-4393）。市の著作物と推定。
- **fest-157（木境大物忌神社の虫除け祭り）**: まいーれ（由利本荘市民俗芸能伝承館）。秋田県由利本荘市矢島地区・県指定無形民俗文化財。なお由利本荘市公式サイト（https://www.city.yurihonjo.lg.jp/yashima/kinenkan/musiyoke01.htm）に同祭の代替画像（images/musiyoke01.jpg・musiyoke02.jpg）あり。
- **fest-170（古和浦祇園祭）**: 観光三重（三重県観光連盟）。撮影クレジット「種橋マミ」。本番採用時は観光三重または撮影者へ連絡し許諾取得が必要。

## 運用方針

1. いずれも明示的な再利用許諾（CC/PD）は確認できていない。
2. 出典明記・「掲載許諾申請中」を credit に付した上で本番掲載済み。
3. 権利者から問い合わせ・指摘があれば、当該画像を**即時差し替え／撤去**する。
4. 会長が各所へ連絡し許諾が取れたら、本リストの「状態」と photos.json の license を更新する。
