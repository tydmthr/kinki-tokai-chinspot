## このファイルの目的

このファイルは、Bizarre Japan関連タスクを別セッション・別タスクで進めるときの共通メモである。  
新しい作業を始める前にこのファイルを確認し、完了した作業・作成物・次にやるべきことを追記する。

特に以下の分断を防ぐ。

- Todoistにあるタスクと、実際に作った成果物のズレ
- Spaceにある資料と、GitHub上の実装作業のズレ
- サイト改修、訪問記、SNS、収益化ロードマップの分断
- 「前に作ったテンプレートがどこにあるか分からない」状態

## 現在の基本方針

Bizarre Japanは、単なる珍スポット紹介サイトではなく、**出典付き異界DB＋巡礼ガイド**として運用する。

編集方針:

- 学術的・誠実・事実中心。
- 怪奇・心霊・オカルト的な煽りは避ける。
- 「民俗」「信仰」「歴史的経緯」「地域の造形文化」の文脈で扱う。
- 掲載判断は地域ではなく「Bizarre Japanらしさ」で行う。
- 私有地、夜間立入危険地、心霊煽りに依存する場所は原則として避ける。
- 迷うものは `editorial_status: "hold"` とし、何を主軸に再構成するかをメモする。

## 作業時の共通チェックリスト

### 文章・編集

- [ ] 怪奇・心霊・オカルト的な煽りになっていない。
- [ ] 民俗、信仰、歴史的経緯、地域の造形文化として扱っている。
- [ ] 事実と主観を分けている。
- [ ] 出典URLを入れている。
- [ ] 不確かな伝承は「伝承では」「地元では」と明記している。

### サイト・DB

- [ ] 住所・緯度経度を再確認している。
- [ ] `spots.json` / `festivals.json` とIDが紐付いている。
- [ ] `visit_status`、`safety_level`、`source_quality`、`editorial_status` の考え方に沿っている。
- [ ] 私有地・危険地・夜間訪問を推奨していない。
- [ ] 変更後にJSON構文チェックまたはビルド確認をしている。

### SNS・収益化

- [ ] Instagram / Threads / Xに転用できる短文がある。
- [ ] ZINE化できる写真・地図・出典メモがある。
- [ ] About、依頼ページ、ポートフォリオにつながる導線がある。
- [ ] YEGや地域貢献の文脈と矛盾していない。
