# Bizarre Japan サイト改修タスク用プロンプト集

作成日: 2026-05-11  
用途: Perplexity Personal Computer / サイト改修タスクへの投入用  
対象サイト: Bizarre Japan / 異界巡礼  
URL: https://bizarrejapan.com/  
GitHub: https://github.com/tydmthr/kinki-tokai-chinspot  

## 共通前提

以下は全タスクで必ず守ること。

- Bizarre Japan は「珍スポット紹介サイト」ではなく、**出典付き異界DB＋巡礼ガイド**として改修する。
- トーンは、学術的・誠実・事実中心。怪奇・心霊・オカルト的な煽りは避ける。
- 「民俗」「信仰」「歴史的経緯」「地域の造形文化」の文脈で扱う。
- 2026-05-11掲載判断ポリシーに従い、全国版へ拡張する。ただし地域ではなく「Bizarre Japanらしさ」で掲載可否を判断する。
- 王道観光地、一般資料館、産業遺産単体、学習施設、行政資料館、企業ミュージアム、一般文化財・史跡・町並み保存地区は原則外す。
- 残すべきものは、B級スポット、奇祭・民俗行事、巨像・私設造形、民俗信仰・供養・祈願の場、異形の展示施設、安全に訪問できる珍スポット。
- 迷うスポットは `editorial_status: "hold"` とし、何を主軸に再構成すべきかをメモする。
- 私有地、夜間立入危険地、心霊煽りに依存する場所は掲載・導線・文言に十分注意する。
- 実装前に必ず、対象パス、変更概要、デプロイ要否を提示する。
- 変更後はビルドまたは静的チェックを実行し、問題がなければデプロイ要否を判断する。

## 施策1: spots.json のスキーマ拡張

### 目的

Bizarre Japan を「出典付き異界DB」として強化するため、訪問可否、安全性、出典信頼度、編集判断をデータとして扱えるようにする。

### 対象パス

- `spots.json`
- `scripts/bulk_add.py`
- `scripts/candidate_builder.py`
- スポット読み込み処理があるJS/TS/HTMLファイル

### 変更概要

- 既存スポットに新フィールドを追加する。
- 既存表示を壊さないよう、フィールド未定義時のフォールバックを実装する。
- 今後の候補CSV生成・一括追加スクリプトも新スキーマに対応させる。

### デプロイ要否

必要。地図・詳細表示に影響するため、ビルド確認後にデプロイする。

### 投入プロンプト

```text
Bizarre Japan / 異界巡礼のサイト改修をお願いします。

対象パス:
- spots.json
- scripts/bulk_add.py
- scripts/candidate_builder.py
- スポット読み込み・表示に関係するフロントエンドファイル

変更概要:
サイトを「出典付き異界DB＋巡礼ガイド」に寄せるため、spots.json のスキーマを拡張してください。既存データを壊さず、未定義フィールドがあっても表示が崩れないようにしてください。

追加したいフィールド:
- visit_status: "visit_ok" | "check_required" | "not_recommended" | "closed_or_private" | "unknown"
- safety_level: "low" | "medium" | "high" | "unknown"
- source_quality: "primary" | "secondary" | "blog_sns" | "unverified"
- editorial_status: "published" | "hold" | "rejected"
- editorial_note: string
- last_verified: "YYYY-MM-DD"
- folklore_tags: string[]
- access_note: string
- best_season: string
- photo_status: "original" | "permitted_external" | "missing" | "unknown"

掲載判断ポリシー:
- 全国版へ拡張するため、近畿・東海以外という理由だけで削除しない。
- 王道観光地、一般資料館、産業遺産単体、学習施設、行政資料館、企業ミュージアム、一般文化財・史跡・町並み保存地区は原則外す。
- B級スポット、奇祭・民俗行事、巨像・私設造形、民俗信仰・供養・祈願の場、異形の展示施設、安全に訪問できる珍スポットを優先する。
- 迷うスポットは editorial_status: "hold" にして、editorial_note に再構成方針を書く。

実装要件:
1. spots.json の既存全件に新フィールドを付与してください。自動判定が難しい項目は "unknown" または空文字で構いません。
2. 既存の category や source との互換性を維持してください。
3. bulk_add.py と candidate_builder.py が新フィールドを扱えるようにしてください。
4. フロント側で未定義フィールドがあってもエラーにならないようにしてください。
5. 変更後、JSON構文チェック、ビルド、可能なら表示確認を実行してください。

完了時に報告してほしいこと:
- 変更したファイル
- 追加したフィールド
- 既存データへの影響
- 実行したテスト
- デプロイしたかどうか
```

## 施策2: スポットカードに安全・出典バッジを追加

### 目的

一覧・地図・カード表示の段階で、訪問可否、安全性、出典の信頼度が分かるようにする。

### 対象パス

- スポットカードコンポーネント
- 地図ポップアップ表示
- 一覧表示テンプレート
- 関連CSS

### 変更概要

- `visit_status`
- `safety_level`
- `source_quality`
- `editorial_status`

をバッジとして表示する。

### デプロイ要否

必要。UI表示変更のため、表示確認後にデプロイする。

### 投入プロンプト

```text
Bizarre Japan / 異界巡礼のスポットカードUIを改修してください。

対象パス:
- スポットカード表示コンポーネント
- 地図ポップアップ表示
- 一覧表示テンプレート
- 関連CSS

変更概要:
各スポットのカードや地図ポップアップで、訪問可否、安全性、出典信頼度、編集状態が一目で分かるようにバッジを追加してください。

表示したいバッジ:
- visit_status
  - visit_ok: 訪問可
  - check_required: 要確認
  - not_recommended: 来訪非推奨
  - closed_or_private: 非公開・私有地
  - unknown: 未確認
- safety_level
  - low: 安全性低リスク
  - medium: 注意
  - high: 危険・要注意
  - unknown: 安全性未確認
- source_quality
  - primary: 一次資料あり
  - secondary: 準一次資料
  - blog_sns: 個人情報中心
  - unverified: 未確認
- editorial_status
  - published: 掲載
  - hold: 保留
  - rejected: 非掲載

デザイン方針:
- 煽り・ホラー調にしない。
- 学術的・落ち着いた色使いにする。
- 危険バッジは目立たせるが、恐怖演出にはしない。
- モバイルで折り返しても読みやすくする。

実装要件:
1. 未定義フィールドでもクラッシュしないようにしてください。
2. 地図ポップアップ内では最大3個程度のバッジに収めてください。
3. カード一覧では visit_status と source_quality を優先表示してください。
4. editorial_status: "hold" は管理・確認用として、一般表示で出すかどうかをコード内で制御しやすくしてください。
5. ビルドと表示確認を実行してください。

完了時に報告してほしいこと:
- 変更したファイル
- 追加したバッジ
- モバイル表示の確認結果
- ビルド結果
- デプロイしたかどうか
```

## 施策8: SNSカード生成用の説明文フィールドを追加

### 目的

Instagram、Threads、X向けに、スポットごとの短文説明を一貫したトーンで生成・表示できるようにする。

### 対象パス

- `spots.json`
- SNS投稿生成スクリプト
- Instagramフィード関連スクリプト
- 管理用CSV生成スクリプト

### 変更概要

スポットごとに、SNS向け短文、注意書き、推奨ハッシュタグを持てるようにする。

### デプロイ要否

表示に使う場合は必要。データ・スクリプトのみなら不要。

### 投入プロンプト

```text
Bizarre Japan / 異界巡礼のSNS運用に使うスポット説明フィールドを追加してください。

対象パス:
- spots.json
- SNS投稿生成スクリプト
- fetch_instagram_feed.py
- candidate_builder.py
- bulk_add.py

変更概要:
Instagram、Threads、Xで使いやすい短文説明を、スポットデータ側に保持できるようにしてください。

追加したいフィールド:
- sns_caption_short: 80〜120字程度
- sns_caption_long: 200〜300字程度
- sns_warning: 訪問注意・撮影注意
- sns_hashtags: string[]
- sns_hook: 1行目に使う導入文

トーン:
- 煽らない。
```
