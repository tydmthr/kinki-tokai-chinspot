# spot-001 平等寺穴弘法 自前撮影記録

| 項目 | 内容 |
|---|---|
| ID | spot-001 |
| 対象 | 平等寺穴弘法（へいとうじ あなこうぼう） |
| 所在 | 三重県亀山市（運営者の地元） |
| 状態 | **`legacy_owned`**（自前撮影、許諾不要） |
| 撮影者 | 運営者本人（豊田元洋） |
| クレジット | 不要（自己所有） |

## 注意

本ファイルはトラッキング体系の最初期スポットであり、
**自前撮影で許諾申請を要しなかった案件のサンプル**として
permission_requests/ 配下に残置している。

`legacy_owned` ステートは「自己撮影／著作権を運営者が保有」を意味し、
許諾申請の対象外として扱う。

spots.json の該当エントリで `photo_credit` フィールドは省略可。
ただし `photo_url` は通常通り必須。
