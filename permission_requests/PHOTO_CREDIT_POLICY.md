# PHOTO_CREDIT_POLICY.md — 写真クレジット・表記ルール

このドキュメントは、Bizarre Japan / 異界巡礼 サイト上の **写真クレジット表記** および `photos.json` の `credit` / `license` フィールドの記入ルールを定めるものです。

## 基本原則

1. **すべての外部提供写真にはクレジットを明記**する。例外なし。
2. クレジット文言は**提供元の指定どおり**に表記する（勝手な省略・改変禁止）。
3. クレジット表記は**サイト上の当該写真直下またはキャプション末尾**に表示する。
4. 自撮影写真は `credit: "撮影：豊田元洋"` で統一。

## photos.json フィールド定義

### `credit`（必須・許諾済写真）

提供元から指定された表記文言をそのまま記入する。

```json
"credit": "©石川県観光連盟"
"credit": "写真提供　あきた美郷づくり株式会社"
"credit": "笠岡市教育委員会 提供"
"credit": "撮影：豊田元洋"
```

### `license`（必須・許諾済写真）

許諾の条件・範囲を簡潔に記録する。

```json
"license": "本サイト掲載目的に限る。再配布不可。利用規約遵守。"
"license": "事前監修なし。民俗文化への配慮の上、当方判断で掲載。"
"license": "暫定。提供元の最終回答待ち。"
```

### `permission_request_ref`（推奨）

`permission_requests/` 内の関連ファイルへの参照パスを記録（追跡用）。

```json
"permission_request_ref": "permission_requests/sent/fest-114_ishikawa-tourism_2026-05-15.md"
```

## クレジット表記パターン

### A. 自治体・公的団体

```
©<団体正式名称>
例：©石川県観光連盟
例：©高鍋町観光協会
```

### B. NPO・観光協会・第三セクター

```
写真提供　<団体正式名称>
例：写真提供　あきた美郷づくり株式会社
```

### C. 神社・寺院

```
<施設名> 提供
例：加太淡嶋神社 提供
```

### D. 個人写真家

```
撮影：<氏名>
例：撮影：山田太郎
```

### E. ユーザー（運営者）自撮影

```
撮影：豊田元洋
```

## サイト上の表示位置

### スポット詳細ページ

- 主写真：写真直下に小さく表示
- サブ写真：各写真のキャプション末尾に表示
- フォントサイズ：本文の 0.75〜0.85em
- 色：本文より薄め（#777 等）

### カード一覧・地図ピン

- カード裏面または詳細リンク先に集約
- カード前面には表示しなくてよい（混雑回避）

### OGP・SNS シェア画像

- 提供写真をシェア画像に使用する場合は、**写真上に直接焼き込む**形でクレジットを表示
- フォントサイズ・位置は読者環境で潰れない大きさを確保

## 利用規約遵守義務

各提供元の利用規約（例：ほっと石川旅ねっと写真ダウンロード規約）に従う。具体的には：

- 第三者への再配布禁止
- ダウンロード可能な形でのサイト提供禁止
- 改変（合成・トリミング以上の編集）禁止
- 商用目的（広告掲載・物販・有料配信）への流用禁止

## 違反時の対応

- 利用規約違反・クレジット誤記が発覚した場合は、**24時間以内に該当写真を一時非公開**にして提供元に連絡
- 修正完了まで再公開しない
