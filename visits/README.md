# 訪問記の書き方

このフォルダに `spot-XXX.md` または `fest-XXX.md` 形式のファイルを作るだけで、サイトに自動的に反映されます。

## 書き方

### ファイル名
- スポットの場合: `spot-001.md` （IDと同じ）
- 祭礼の場合: `fest-001.md`

### フォーマット例

```markdown
---
visited_date: 2026-03-15
companions: 一人
weather: 晴れ
duration: 約2時間
rating: 5
---

# 田縣神社・豊年祭を見てきた

## 行ってみたきっかけ

商工会議所の研修旅行で…（自由に書く）

## 印象に残ったこと

御神体の大きさは想像以上で、地元の老人がこともなげに

## 写真

![豊年祭の行列](photos/spot-001/img-01.jpg)
*神輿の出発前*

![境内の奉納物](photos/spot-001/img-02.jpg)

## また行きたいか

行きたい。次は早朝の祈祷から見たい。
```

## 写真の置き方
1. `photos/spot-001/` のようにスポットID別フォルダを作る
2. 写真ファイル（jpg/png）を入れる
3. Markdown 内では `photos/spot-001/img-01.jpg` のように相対パスで参照

## フロントマター（先頭の `---` で囲んだ部分）の項目
- `visited_date`: 訪問日 (YYYY-MM-DD)
- `companions`: 同行者
- `weather`: 天気
- `duration`: 所要時間
- `rating`: ★評価 1〜5

すべて任意。書きたいものだけ書けばOK。

## サイトでの表示
スポット詳細を開くと「★訪問済み・体験談を読む」ボタンが出現し、クリックで全文表示されます。
