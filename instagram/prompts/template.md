# 文字入れプロンプト テンプレ

写真背景＋文字入れ画像を生成／編集する時に使うプロンプトのひな型。
背景写真の上に、クレー（Klee）系フォントで日本語テキストを載せる前提。

---

## 基本仕様

- 画像サイズ：1080 × 1350（縦4:5）
- ベース：背景写真（`assets/backgrounds/` から指定）
- フォント優先：Klee One / Klee 系 → ヒラギノ明朝 → しっぽり明朝
- カラー：白文字＋うっすら影、または黒文字＋白フチ（背景の明度で判断）
- 余白：上下左右 80px 以上の安全マージン

---

## プロンプトひな型（生成AI向け）

```
縦長 1080x1350 のInstagram投稿画像を作って。

背景：{{背景画像のパス or 説明}}
※ 背景写真の上に文字を載せるだけ。背景は加工しない。

タイトル文字（中央上寄り、大きめ、クレー系の太め日本語フォント）:
"{{タイトル / 30文字以内}}"

サブ文字（タイトル直下、小さめ、明朝寄り）:
"{{サブ / 場所・カテゴリなど 20文字以内}}"

右下に小さく投稿タイプのラベル:
"{{資料メモ / 訪問候補メモ / 現地訪問記}}"

左下に小さくアカウント表記:
"@bizarre_japan"

文字色は背景に応じて白 or 黒。読みやすさ最優先。
装飾は最小限、明朝の細さを活かしたシンプルな佇まいで。
```

---

## 黒背景カード（予備）用プロンプト

写真が用意できないときの予備版。

```
縦長 1080x1350、純黒（#0a0a0a）背景のInstagram投稿画像を作って。

中央にクレー系の太め日本語フォントで:
"{{タイトル}}"

タイトル下に明朝細字で:
"{{サブ}}"

右下に小さく:
"{{投稿タイプ}}  @bizarre_japan"

文字色は生成り（#f5f1e8）。余白広めで上品に。
```
