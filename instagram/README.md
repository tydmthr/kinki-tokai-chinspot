# Bizarre Japan / Instagram 運用フォルダ

近畿・東海珍スポット（kinki-tokai-chinspot）と連動した Instagram アカウント **Bizarre Japan** の運用ファイル一式。

投稿の素材（背景画像）、書き出し画像、台本ドラフト、文字入れ用プロンプトなどをここに集約する。

---

## 運用方針

- **言語**：日本語メイン（英訳キャプションは余裕があれば追加）
- **訪問ステータス**：未訪問のスポットは必ず「未訪問」と明記する。現地で確認したかどうかを曖昧にしない
- **投稿タイプ**：以下3種類のいずれかに分類する
  - `資料メモ` … 文献・Webで調べた段階のメモ。未訪問前提
  - `訪問候補メモ` … 行きたい場所として温めている段階
  - `現地訪問記` … 実際に行った報告。一次情報
- **ビジュアル**：写真背景＋文字入れを基本にする。写真が用意できないときの予備として黒背景カードを使う
- **画像サイズ**：1080 × 1350（縦4:5）
- **フォント**：クレー（Klee）系を優先。代替はヒラギノ明朝・しっぽり明朝など手書き／明朝寄り
- **ハッシュタグ**：最大5件まで（盛らない）
- **投稿ペース**：毎週3本候補を作る → 最低1本投稿できればOK。完璧を狙わず継続を優先

---

## フォルダ構成

```
instagram/
├── README.md               … このファイル（運用方針）
├── prompts/                … 画像生成・文字入れ用プロンプトのひな型
│   └── template.md
├── assets/
│   ├── backgrounds/        … 背景写真（撮影 or 自前素材）
│   └── exports/            … 文字入れ済みの最終書き出し画像
├── scripts/                … 画像生成・一括処理スクリプト（今後追加）
└── drafts/                 … 投稿台本ドラフト（キャプション・タグ含む）
    └── template.md
```

---

## 1本の投稿を作る流れ

1. `drafts/` にドラフトを新規作成（テンプレ参照）
2. 投稿タイプを決める（資料メモ / 訪問候補メモ / 現地訪問記）
3. 背景画像を `assets/backgrounds/` に置く
4. `prompts/` のテンプレを使って文字入れ指示を作る
5. 書き出した画像を `assets/exports/` に保存
6. ドラフト完成 → Instagramに投稿

---

## 命名ルール

- ドラフト：`drafts/YYYY-MM-DD_スポット名.md`
- 背景画像：`assets/backgrounds/YYYY-MM-DD_スポット名_01.jpg`
- 書き出し画像：`assets/exports/YYYY-MM-DD_スポット名_01.png`

日付は撮影日 or 取材日（無ければ作成日）。
